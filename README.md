## About Me

I am a Computer Vision Engineer at **Aremak Bilişim Teknolojileri** and an M.S. Computer Engineering student at **Bilkent University**.

My work focuses on building practical AI systems that connect machine learning models with cameras, backend services, industrial hardware, and user-facing applications.

- Developing multi-camera industrial inspection systems using C++, Qt, OpenCV, and industrial camera SDKs
- Working on deflectometry, photometric stereo, segmentation, classification, pose estimation, and defect detection
- Building deep learning applications with PyTorch, TensorFlow, YOLO, and CNN-based architectures
- Developing LLM and RAG applications using FastAPI, LangChain, Gemini, Hugging Face embeddings, and Chroma
- Researching representation learning, automated program repair assessment, and graph visualization
- Contributing to [Newt Editor](https://web.newteditor.org/), a biological network visualization platform
